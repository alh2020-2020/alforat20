# متجر الفرات موبايل — متجر إلكتروني متكامل

موقع عربي متجاوب للجوال والكمبيوتر، بتأثيرات انتقال سلسة ورسومات للهواتف، وسلة مشتريات، وتسجيل طلبات في قاعدة بيانات، ولوحة تحكم لإدارة المنتجات والصور والفيديوهات والطلبات.

## معاينة فورية بدون خادم

افتح الملف `معاينة_فورية.html` لمشاهدة تصميم المتجر وتجربة التصفح والبحث والسلة. **هذه معاينة فقط**؛ لا تحفظ الطلبات على الخادم ولا تتيح إدارة المنتجات. الميزات الكاملة تعمل عند تشغيل الخادم حسب التعليمات التالية.
بعد تغيير ملفات الواجهة أو بيانات البذرة، أعد إنشاء المعاينة بالأمر `python build_preview.py`. تستخدم المعاينة الأصناف الأولية الموجودة في `data/catalog_seed.json`؛ بيانات لوحة الإدارة المخزنة في SQLite تظهر في الموقع الذي يعمل بالخادم فقط.

## تشغيل الموقع على الكمبيوتر

1. تحتاج Python 3.10 أو أحدث، وإنترنت لتثبيت المتطلبات لأول مرة.
2. افتح الطرفية داخل مجلد المشروع وشغّل:

   ```bash
   python -m pip install -r requirements.txt
   python app.py
   ```

   على لينكس / ماك يمكنك تشغيل `./start.sh`.
3. افتح `http://localhost:8000` لمشاهدة المتجر، و`http://localhost:8000/admin` للوحة التحكم.
4. **في أول تشغيل** تُنشأ كلمة مرور عشوائية آمنة للمدير وتظهر في الطرفية. انسخها واحتفظ بها، ثم غيّرها من تبويب **الأمان** في لوحة التحكم. يمكنك أيضاً تحديدها قبل التشغيل بمتغير البيئة `ADMIN_PASSWORD`، على أن تكون قوية.

> يجب تشغيل الخادم عبر `python app.py`. فتح ملف `index.html` مباشرة لا يُشغّل الكتالوج والطلبات.

## أهم الميزات

- تصميم عربي `RTL` متجاوب، مؤثرات دخول وتحريك البطاقات ومجسمات CSS، وضع فاتح اختياري، ودعم تقليل الحركة.
- عرض المنتجات بالصور والأوصاف والأسعار والمخزون والأقسام، مع بحث وفلاتر وترتيب.
- إضافة المنتجات وتعديلها وحذفها ورفع صورها من لوحة التحكم؛ الصور تحفظ في `uploads/`.
- سلة تسوق، نموذج تأكيد الطلب، وتسجيل الطلبات في SQLite مع رقم مرجعي وحالة تنفيذ.
- خيارات طريقة الدفع للاختيار والتنسيق، **دون تحصيل مدفوعات إلكترونية حقيقية**.
- إدارة فيديوهات يوتيوب (تضمين تشغيل) وروابط فيديوهات المنصات الأخرى (فتح الرابط الخارجي).
- إضافة روابط واتساب وفيسبوك وإنستغرام وتيك توك ويوتيوب وتيليجرام وسناب شات ومنصة X.
- استيراد منتجات JSON أو CSV، وتصدير نموذج CSV للاستيراد.
- تثبيت اختصار كتطبيق ويب PWA عند النشر مع HTTPS ومتصفح داعم.

## ربط تطبيق إضافة المنتجات

**رابط التطبيق لم يصل بعد.** يوجد في لوحة التحكم حقل لإظهاره على الموقع، لكن **المزامنة المباشرة لا تعمل تلقائياً حتى تتوفر طريقة مناسبة لجلب بياناته**. بعد توفير الرابط، يلزم تحديد أحد هذه الطرق: API يسمح بتصدير/قراءة المنتجات، ملف JSON أو CSV، أو بيانات دخول مخوّلة للنظام إذا كان يدعم الربط التقني. من دون ذلك، استخدم الاستيراد اليدوي للملفات أو لوحة التحكم مباشرة.

صيغة JSON للاستيراد:

```json
{
  "products": [
    {
      "name": "سماعة لاسلكية",
      "category": "السماعات",
      "description": "وصف المنتج",
      "price": 15000,
      "old_price": 18000,
      "image_url": "https://example.com/image.jpg",
      "badge": "وصل حديثاً",
      "featured": true,
      "stock": 25
    }
  ]
}
```

`price: 0` يعني السعر عند الطلب، و`stock: -1` يعني كمية غير محددة في الموقع.

## نشر الموقع على الإنترنت

- يجب استخدام استضافة تدعم Python/FastAPI مع تخزين دائم لكل من `data/` و`uploads/`.
- استخدم **HTTPS** ونسخاً احتياطية منتظمة، وحدد نطاقاً خاصاً بالمتجر.
- يفضّل استخدام خادم أمامي مثل Caddy أو Nginx ومراقبة الخادم وتقييد معدلات الطلبات قبل التشغيل التجاري واسع النطاق.
- يمكن تشغيل المشروع باستخدام Docker بعد تحديد كلمة مرور قوية عبر `ADMIN_PASSWORD=... docker compose up --build`. تذكّر استخدام HTTPS عند نشره على نطاق عام.
- عند النشر على استضافة سحابية يمكن تشغيل `uvicorn app:app --host 0.0.0.0 --port $PORT` بعد إعداد المتغيرات اللازمة.
- **المدفوعات البنكية أو بوابات البطاقات ليست موصولة بعد**؛ لا تطلب من الزبائن بيانات البطاقات في هذه النسخة.
- واجهة المنتجات الأولى بيانات **تجريبية** بصور مرسومة وليست أصنافاً مؤكدة أو أسعاراً حقيقية. عدّلها قبل النشر.
- لا تستخدم هذه النسخة لتأكيد طلبات بكميات كبيرة قبل اختبار الربط والنسخ الاحتياطي وسياسات الخصوصية الخاصة بمتجرك.

## ملفات المشروع

- `app.py` — خادم FastAPI وSQLite وواجهات الإدارة والطلبات.
- `static/index.html` و`styles.css` و`app.js` — واجهة المتجر.
- `static/admin.html` و`admin.css` و`admin.js` — لوحة الإدارة.
- `static/assets` — الأيقونات والشعار التوضيحي.
- `uploads/` — الصور المرفوعة.
- `data/` — قاعدة بيانات المتجر بعد التشغيل.

حقوق هوية متجر الفرات موبايل محفوظة لصاحبها. الشعار الحالي توضيحي ويمكن استبداله من لوحة التحكم بالشعار الحقيقي.

## ربط تطبيق الفرات موبايل الحقيقي — نوفمبر 2026
الرابط المؤكّد: https://play.google.com/store/apps/details?id=com.forat.storeapp
لا تحتوي صفحة Google Play على منتجات التطبيق الداخلية أو الأسعار أو مواصفات كامل المخزون. لذلك **لم يتم الادعاء بعمل مزامنة مباشرة** ولا اختراع أسعار أو منتجات.
- يدعم الموقع الآن مواصفات المنتج (قاموس خصائص مثل الشاشة والمعالج والبطارية والسعة)، الماركة، الموديل، SKU، معرّف المنتج في تطبيقك، روابط صورة وفيديو وصفحة المنتج. تظهر المواصفات بالتفصيل في نافذة المنتج.
- يدعم استيراد ملفات CSV/JSON بمئات المنتجات، والتحديث عند تكرار `sku` أو `external_id` بدلاً من عمل نسخ مكررة. الحذف غير تلقائي، حفاظاً على التعديلات والطلبات.
- تم إضافة المواصفات المعلنة **فقط** لأربعة منتجات من صور إعلانات المتجر السابقة. المواصفات دعائية وتحتاج إلى تأكيد قبل البيع، والمنتجات الأخرى مجرد أقسام أولية بصور توضيحية.
- عند استلام تصدير رسمي من تطبيقك أو API مصرح به، استخدم استيراد `CSV/JSON` عبر `/admin`. استيراد مباشر دوري يحتاج إعداد API موثوق وصلاحيات إضافية.
- `price=0` يعني السعر عند الطلب و`stock=-1` مخزون غير مؤكد.
- اترك خانة المواصفات فارغة عندما لا تتوفر بيانات مؤكدة؛ لا تكتب مواصفات متخيلة.
- للحفاظ على قاعدة البيانات القديمة، يضيف الخادم أعمدة جديدة تلقائياً عند أول تشغيل.

- **قيود مهمة:** رابط المشاركة `/share/...` ليس رابط صفحة أصلياً يمكن استخدامه دائماً في Facebook Page Plugin. يمكن ضبط `facebook_page_url` في إعدادات المتجر بعد الحصول على عنوان الصفحة المباشر (`facebook.com/PageName`) لتفعيل التضمين؛ التضمين يعتمد على إعدادات Meta.
- **لم تتم مزامنة منشورات الصفحة تلقائياً** أو استخراج فيديوهاتها؛ يتطلب ذلك وصولاً معتمداً إلى Meta Graph API وتفويض الصفحة أو تزويدنا بروابط المنشورات العامة بصورة مباشرة. لا تُخزّن كلمات مرور فيسبوك أو رموز وصول حساسة في رابط معلن.
- نُقلت نسخة من أعمال الإعلانات السابقة تحت `static/assets/ads` مع تهيئة `data/social_seed.json`. التهيئة تحدث مرة واحدة فقط لكل قاعدة بيانات حتى لا تعود الإعلانات المحذوفة.
